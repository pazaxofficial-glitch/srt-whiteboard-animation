# Demo project

Four script lines and three images (two SVG drawings and one PNG) to try the app.

- `*Spartan*` and `*shield and a spear*` are marked, so the hand writes them on the board when they are spoken.
- Line 4 has no image, so it is written out word by word.

1. Start the app and create a new video.
2. Paste `script.txt` into the script box and drop the three files from `images/`.
3. Record yourself reading the four lines (any voice recorder) and upload it as the narration.
4. Press **Make video**.
